pub(all) struct Stream

One exchange on a connection, named by the connection rather than by the protocol underneath: on a connection that carries one exchange at a time it is 1, and on one that multiplexes it is whatever that connection gave out.

pub(open) trait Conn

The one contract a connection presents, whatever carries it: HTTP/1.1, HTTP/2, HTTP/3 or WebSocket. Code written against this runs on any of them; an implementation is all a new protocol needs.

An exchange is opened, the request body is sent through it, and the reply's head and body are read from it. A connection that carries one exchange at a time says so through is_ready, which a caller waits on before opening the next.

async fn open(Self, Request) -> Stream

Open an exchange on request, and send its head and whatever body came with it.

async fn send(Self, Stream, Bytes, end~ : Bool) -> Unit

Send more of the request's body; end marks the last of it. Only an exchange opened with Body::Streaming takes this.

async fn response(Self, Stream) -> Response

The reply's head, once the peer has sent it.

async fn read(Self, Stream) -> Bytes?

The next run of the reply's body, read as it arrives; None ends it.

fn trailers(Self, Stream) -> Array[Field]

The fields that came after the body, once read has ended it.

fn is_ready(Self) -> Bool

Whether another exchange can start on this connection now. False while one is in flight on a connection that carries them one at a time, and after it has ended.

fn kind(Self) -> String

The protocol the connection settled on, as ALPN names it: http/1.1, h2, h3.

async fn close(Self) -> Unit

End the connection, in whatever way the protocol under it asks for.

pub(all) enum Liveness

What a reused connection is asked before it is handed out again.

None_

Nothing: a connection that served an exchange is taken on trust until the next one fails, which is what most clients do.

Peek

A read that does not wait. A peer that has closed is dropped; one that has said something while idle keeps what it said for the next exchange.
